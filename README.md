# ASL Letter Recognition

Welcome to the **ASL Letter Recognition** project! This repository provides resources and code for recognizing American Sign Language (ASL) letters using machine learning. The project is implemented primarily in Jupyter Notebook, making it easy to follow along with the exploration, modeling, and evaluation steps.

## Features

- **Jupyter Notebook based**: The main code is provided in an interactive notebook—ideal for step-by-step demonstrations, experimentation, and reproducibility.
- **Focus on ASL**: All code and analysis are tailored for the classification of ASL gestures representing individual letters.
- **Accessible and extendable**: Designed for students, researchers, and hobbyists interested in computer vision and sign language recognition.

## Contents

- [`ASL Letter Recognition.ipynb`](ASL%20Letter%20Recognition.ipynb): The main notebook containing the data handling, model building, training, evaluation, and visualization.

## Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Mayur-Shashidhar/ASL-Letter-Recognition.git
   cd ASL-Letter-Recognition
   ```
2. **Open the notebook**:
   - Launch Jupyter Notebook or JupyterLab.
   - Open `ASL Letter Recognition.ipynb`.
3. **Install dependencies**: Ensure you have Python and necessary libraries (e.g., numpy, pandas, matplotlib, scikit-learn, tensorflow/keras) installed.

## Usage

Run through the notebook cell by cell to explore the full pipeline—from loading and preprocessing the ASL dataset, building a machine learning model, training, to evaluating its performance.
